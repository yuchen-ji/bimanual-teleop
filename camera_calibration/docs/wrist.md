# 腕部相机手眼标定

运行采样命令后，**操作者用机器人示教器调整机械臂，程序在停稳后自动保存样本**。程序只读取相机和实际关节反馈，不会使能、回位、开启拖动模式或发送运动目标。

## 准备

使用已有 4×5 非对称圆点板，同一直线相邻圆心距离为 100 mm，交错步长为 50 mm。把板固定在支架或桌面上，不要手持；板与机器人基座在整次采样中固定，相机安装保持不变。

先按[总览](../README.md)安装环境，关闭占用相机或机器人 UDP 4730 的程序。在示教器上准备好所选机械臂的低速手动点动；若现场已有厂家配置并验证过的拖动示教，也可由操作者在厂家控制端启用。采样程序不会替你切换机器人模式。未启用拖动模式时，不要直接用手推拉机械臂。

**不要同时运行本项目的 Quest 遥操作、`scripts/jog_tianji.py` 或其他 SDK 控制程序。** 它们与采样程序使用同一个 UDP 反馈接收端，当前不支持并行控制与采样。这里的示教器指独立于本采样 SDK 连接的厂家控制端；若现场只有 Quest／本项目点动可用，当前命令尚不能完成边控制边采样，需要新增共用连接的控制采样入口。

## 采样：本地 USB 电脑

建议在一个会话中先采左腕、再采右腕，每次只调整一只机械臂，另一臂停在不遮挡、不干涉的位置。所有命令在项目根目录、已激活的 `bimanual-teleop` 环境中执行：

```bash
python camera_calibration/run.py wrist collect \
  --side both --same-row-mm 100 --samples 20 \
  --output camera_calibration/data/wrist_capture
```

默认连接机器人 `192.168.1.190`，左右相机序列号分别为 `408322072104`、`408322070938`。可用 `--robot-ip`、`--left-serial`、`--right-serial` 覆盖。无桌面时使用 `--no-preview`，通过终端提示确认进度。输出目录必须是新目录。

### 启动后怎样操作机械臂

1. 等待预览出现，通过示教器低速移动所选机械臂，让腕部相机完整看到板的 **20 个圆点**。移动机械臂时板保持固定，灵巧手不要挡住相机或圆点。
2. 松开点动按钮并保持当前姿态 **1～2 秒**；拖动示教时也要让机械臂真正停稳。程序检查板检测、关节静止、图像与反馈时间对应及姿态重复情况。
3. **不用按 Enter、空格或拍照键。** 有效样本自动保存，终端出现 `Saved left 1/20: PnP ... px`，预览计数随之增加。只有计数增加才表示本组已记录。
4. 看到保存提示后，再通过示教器换到下一个姿态。改变相机相对板的位置、距离及俯仰／偏航／滚转；相机始终看板的同一面。每侧至少 15 组，建议 20～30 组。不要只平移、只绕同一轴旋转或反复停在相近姿态。
5. 每侧达到 `20/20` 后停止采该侧；所选两侧都达到目标后自动保存并结束。提前结束可在预览窗口按 **Q**、关闭窗口，或在终端按 **Ctrl+C**；已保存样本保留。结束采样后，机器人保持／退出拖动等操作仍由示教器完成，**Q 只结束采样，不是机器人停止指令**。

可以按“板在画面中央／四周、较近／较远、向不同方向倾斜”的顺序分配姿态，让圆点覆盖不同画面位置并留边；移动范围以完整看板且机械臂不干涉为准。不要为凑数量使用极端斜视或仅沿单轴重复移动。

### 计数不增加时

| 窗口／终端提示 | 操作 |
| --- | --- |
| `show all 20 circles` | 调整机械臂，让全部圆点入镜，检查遮挡和反光 |
| `leave a margin around all circles` | 稍微后退或重新居中，让圆点远离画面边缘 |
| `hold wrist still for 1-2 seconds` | 停止点动／拖动，保持姿态；检查机械臂是否缓慢下滑 |
| `pose already saved; vary orientation` | 换一个明显不同的姿态，尤其增加不同方向的转动；继续等待不会重复保存 |
| `waiting for synchronized feedback` / `feedback gap...` / `image/feedback mismatch...` | 先停稳；若持续出现，检查机器人网络及是否有其他 SDK 程序占用连接 |
| `Planar pose is ambiguous...` / `Board reprojection RMS...` | 增加适度倾斜，避免模糊、反光和过度斜视，再停稳 |

### 换另一只手腕

看到 `left 20/20` 后，用示教器把左臂移到不遮挡的位置，调整右臂，让右腕看到同一块固定板，再重复上述步骤，直到 `right 20/20`。此时程序仍在同一个采样会话中，不必退出重启；两只相机不必同时看到板。

只标定一侧时，将 `--side both` 改为 `--side left` 或 `--side right`，该侧达到目标数量就会结束。`left`／`right` 始终指机器人自身的左／右侧。`--samples 20` 是每侧 20 组，双侧共 40 组。

上传整个输出目录，包含 `session.json`、`samples.jsonl` 和原始 PNG。原图不旋转；左腕预览旋转 180° 便于观察，求解使用原始像素，录制方向在输出适配时转换。

手工拍摄可参考[关节记录模板](wrist-manual-template.csv)，需要整理成同样的采样会话格式后解算。

## 求解与验收：完整项目

```bash
python camera_calibration/run.py wrist solve \
  camera_calibration/data/wrist_capture \
  --output camera_calibration/data/wrist_result
```

查看 `result.json` 和 `*_heldout_*.png`，双侧会话只需解算一次。独立验证样本不参加手眼拟合；失败会以非零状态退出。报告中的 `T_flange_sensor_opencv` 是原始彩色光学坐标到法兰的变换，`T_world_board` 是板到项目世界坐标的变换。

## 显式应用

```bash
python camera_calibration/run.py wrist apply camera_calibration/data/wrist_result/result.json
```

只接受通过验证的实测结果，并检查机器人 URDF 哈希。应用后更新仿真腕部配置及来源记录，重启仿真生效。回退时将仿真配置的 `cameras.wrist_calibration_file` 设为 `null`。
