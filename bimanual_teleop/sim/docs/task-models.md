# 导轨任务 CAD 与装配

来源：`/home/jiyuchen/project/WYS/导轨任务模型/`。原文件保持原样，所用文件复制到 `sim/assets/source/rail_task/`；派生网格和来源哈希保存在 `sim/assets/generated/`。模型输入与直接运行的派生模型均由 Git 跟踪，克隆仓库即可取得；采集数据和运行缓存仍不进入 Git。

| 部件 | 使用的源文件 | 默认行为 |
| --- | --- | --- |
| 长导轨 | 导轨长.SLDPRT | 提取源文件缓存的完整封闭三角网格，保留折弯截面和全部孔，约 480 × 45.82 × 25.71 mm |
| 长导轨台 | 导轨台长.step | 原始 CAD 可见网格；较轻的静态三角面碰撞网格测量表面误差不超过 0.1 mm；底面置于桌面 |
| 桌子 | table.STEP | 1.00 × 0.67 m，高 0.73 m；保留桌腿，机器人在窄边 |
| 转运箱 | EU塑料转运箱.STEP | 外形 493 × 348 × 182 mm；每侧一列五层，层距 178 mm，沿用源场景 4 mm 套叠量 |
| 六维力传感器 | 模拟六维力传感器.step | 每个法兰连接一个，轴向厚度 40 mm |
| 腕部相机及支架 | 腕部相机及其支架.step | 支架、相机本体与前盖分别保留几何；支架安装板厚 2 mm |

场景由以上在用部件组装，满足两侧各五层的要求。仿真资源中已删除短导轨、短支架、参考整场景和旧相机等未使用文件。天机与 Wuji Hand2 仅保留使用的关节 URDF 和所引用 STL，机器人仍有 14 个臂关节和 40 个手关节；用户提供的项目外原始模型目录保持原样。

世界坐标为 +X 从机器人指向桌子远端、+Y 向机器人左侧、+Z 向上。桌子地面投影中心在 (0.78, 0)，长边沿 X。料箱侧和成品箱侧的箱堆中心分别为 (0.72, +0.56) 和 (0.72, -0.56)，底箱落地，上层箱口高度 0.894 m。箱子使用静态开口网格碰撞，内部空腔保留。480 mm 导轨放入上层箱时需要适当斜放；箱内尺寸较短，不宜要求其长轴与箱体完全平行。

两臂装配顺序均为：**TCP 法兰 → 六维力传感器 → 腕部相机支架 → Wuji Hand2**。手安装面比原先增加 42 mm。右侧相机支架绕法兰轴旋转 180°，并补偿手的相对安装角，使左右相机都在手心侧且手的原有朝向不变。三路图像仍是头部、左腕、右腕。腕部虚拟光心根据 CAD 前盖设置，视轴初始化指向手心；它不是实机相机外参标定结果。

导轨上 CAD Y=102 mm 与 367 mm 的两孔用于对齐，相距 265 mm，孔径分别约 8.9 与 8.0 mm。长导轨台两销半径约 3.091 与 3.342 mm，最小径向间隙约 0.66 mm。预处理通过实际两孔与两销做平面刚体配准，不缩放模型。默认位姿和 Reset 均使用此配准结果。导轨受重力、接触和摩擦作用，未固定在台上；受控放置时应先对准再缓慢下放，20 mm 自由跌落不保证自行插入。

导轨碰撞由源网格的底板带孔三角形和端面截面分解为凸棱柱，保留定位孔和开口截面；不用一个填实孔的凸包。清单记录缓存网格解码的拓扑归属与设计历史警告，仿真不依赖这些历史记录。预处理检查网格封闭性、绕序、碰撞体总体积及孔内无凸碰撞体。

六维数据读取两个传感器输入固定关节的反力，坐标为各传感器局部坐标，单位 N、N·m，包含工具重力和惯性。传感器质量 0.2304 kg、相机与支架合计质量 0.20 kg、导轨质量 0.8 kg 均为仿真假设，需要实测后更新；不等同于传感器噪声、应变或去皮模型。末端数据仍使用肩部原点到 TCP 法兰，数据字段和关节顺序保持一致。

重新生成时先关闭正在运行的 Isaac，在已激活的 `bimanual-teleop` Conda 环境中运行：

```bash
PIP_USER=false python -m pip install -r bimanual_teleop/sim/requirements-assets.txt
bimanual_teleop/sim/docker/install-cad-reader.sh
python -m bimanual_teleop.sim.assets
```

只更新任务 CAD 和工具装配可用 `python -m bimanual_teleop.sim.cad_assets`，默认读取仓库内六个在用 CAD；也可通过 `--source` 指定替换目录。修改导轨或导轨台几何后，需重新核对清单中的配准位姿并更新 YAML 的 `rail.initial_center`、`rail.initial_rpy_deg`、尺寸与孔销参数；目前不是任意 CAD 的自动装配器。仅移动整套桌面布局也应同步移动导轨初始位置。

SLDPRT 预处理使用固定 MIT 版本 sldkit 0.1.0（提交 `c43b5ef752a0e58535b7f8f744f7d7c68e3c0e90`）。安装脚本优先复用本机缓存 wheel；新机器首次构建需要网络下载临时 Rust 工具链，结束会清理编译源码与工具链。日常启动 Isaac 不需要 CAD 阅读器和编译器。这两个目录都由 Git 跟踪，日常迁移直接克隆即可，省去转换。

启动仍然只需 `python -m bimanual_teleop.sim`；B 键无名称分段与原始数据格式沿用现有实现。物理和三相机验收报告在 `sim/data/cad-validation/report.json`，验收图在同目录；这些不是学习示范。
