# 天机官方 SDK 迁移验证

2026-09-17：控制、运动学、回位、点动、清错、六维力及离线诊断统一使用随包官方 SDK。已删除旧 C ABI 桥接及其构建、下载和补丁流程。运行平台为 Linux x86_64，Python 使用 Conda `bimanual-teleop`。

## 软件验证

- 迁移前基线：600 项 Python 测试通过。
- 迁移后：`python scripts/run_tests.py discover -s tests` 共 611 项测试通过，耗时约 46 秒。用官方接口测试替换旧原生发送回执／队列测试，保留现有控制生命周期、故障、期限、暂停恢复和退出回归。
- 官方控制库 `100343014` 可加载，类型兼容检查通过；验证整数查询使用 Linux 64 位 `long`，原始 DCSS 反馈不进行四位小数截断。
- 官方运动学与旧桥接的 60 组双臂 FK／雅可比对比已在迁移前完成：FK 矩阵最大元素差约 `1.03e-11`（原生单位），雅可比最大差约 `2.22e-16`。雅可比有限差分最大差约 `3.13e-10`；当前测试继续覆盖此有限差分校验、约束和历史 IK 回放。
- 构建 `py3-none-linux_x86_64` wheel，无天机编译步骤。临时目录展开后，包内六个官方文件哈希全部匹配清单，双臂 FK／IK／雅可比运行通过；进程只加载官方 `libKine.so`，未加载控制库或旧桥接。
- 临时安装位置的回位、清错、遥操作、点动四个入口可加载，均提供 `--sdk-root`。源码与运行文档不再引用旧桥接；`--library` 明确提示迁移方式。
- 将源码、脚本与配置复制到另一独立目录后，六个天机入口、默认配置与模型定位均通过检查；无需外置 SDK 或旧桥接。最后对六维力、离线分析及 SDK 边界追加的 37 项检查也全部通过。

所有测试均未连接真实机器人。官方原始文件及完整性清单见[随包 SDK](../../../bimanual_teleop/vendor/tianji/README.md)。

## 现场验收

仍需在设备现场依次验证：只读反馈及六维力、清错、低速单臂回位／点动、双臂／Wuji 联动、暂停恢复、输入中断和退出。离线测试不证明真实网络时序或物理停机。

官方 `SDK_SUBMITTED` 仅表示 API 接受命令。反馈时间是主机观察时间，底层发送结果与发送时间不可观测，已提交命令不能由项目在底层取消。具体生命周期及能力边界见[开发参考](../../development.md#天机官方-sdk)。
